# 평가 범위

초안 E01–E24 전체의 실증 합격이나 예측력을 주장하지 않습니다. `uv run pytest -q`는 네트워크와 유료 모델 호출 없이 실행합니다.

| 영역 | 구현된 검사 | 남은 범위 |
| --- | --- | --- |
| 근거 | 참조 무결성, 중복 ID, 날짜 cutoff, 검증 상태, 숫자 차원, 대표 확률 표현 | 원문 의미와 주장의 실제 일치, 출처 계보의 자동 추론 |
| 계산 | DCF, 비단조 최초 교차, 재고 이중 계산, 원금/기회비용 중복, 미확인 자금, 손익분기 | 추정계수 검증, 실제 거래 해제·정정 ETL, 전월세 계약 구분 |
| 실행 | 초기 독립 분석, 논의 의존성, 실패/재시도, 예산, 재개, outbox 중복 방지, 태그 신뢰 경계 | 다중 호스트 lease/heartbeat, 장기간 장애 주입 |
| 변경 | 참조 claim stale, 예산 보존, 원자료 재확인과 판단/감사 | valuation/scenario 전체 의존 그래프와 자동 모델 재추정 |
| 연구 | 명시적 미해결 상태, 감사 해결 이유, 조건부 보고서 | 정책 인과 식별, 지역 블록 walk-forward, forward 평가, 동일 예산 single-agent 대조 |

실제 연구를 평가할 때는 원문을 사람이 열어 확인한 대표 질문과 동일 기간·단위의 원자료를 별도로 고정해야 합니다.
